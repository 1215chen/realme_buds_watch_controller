# AI 使用说明（AI Usage Disclosure）

本项目在开发过程中**大量使用了 AI 编码智能体**，为了开源透明度，特此说明。

## 生成方式

- 代码、文档、设计稿的主体由 **AI 编码智能体（DeepSeek Harness）** 在人工需求指导下生成与迭代；
- 人工负责：
  - 提出需求、确定产品范围与设计方向；
  - 在真实 Wear OS 手表与真机耳机上完成功能验证；
  - 抓取并核对耳机通信帧，校准命令表；
  - 对代码、文档、截图进行最终审查与取舍。

## 具体比例（大致）

| 部分 | 说明 |
|---|---|
| Kotlin 源码 | 主要由 AI 生成，人工通过真机测试反馈驱动修复与调整 |
| Wear M3 页面/组件 | AI 生成，人工确认设计方向与真机效果 |
| 协议实现与命令表 | AI 依据分析资料生成初版，人工真机抓包校准后才标记为「已验证」 |
| 文档/README | AI 生成初稿，人工校对事实与表述 |
| 真机截图 | 人工在真实设备上截取 |

## 对使用者的提醒

- **不要假设所有代码都经过严格工程审查**：这是一个个人开源项目，未经过正式安全审计；
- 涉及蓝牙、私有协议的部分请自行评估风险，尤其是刷写固件等操作（本项目未实现 OTA）；
- 若你发现 AI 生成的错误（代码缺陷、文档不准确、协议描述错误），欢迎提交 Issue / PR。

- 本项目不是 realme / OPPO 官方项目，不包含官方源码或素材；
- 协议信息来自公开可见的客户端行为与自行抓包分析，仅供互操作研究与个人学习；
- 请遵守所在地区法律及设备厂商的用户协议；因使用本软件产生的任何后果由使用者自行承担。
