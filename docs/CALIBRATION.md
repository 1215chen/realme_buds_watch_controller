# 真机协议校准记录（realme Buds T200 作为测试机）

> 测试时间：2026-11-13 23:11–23:18
> 连接方式：BLE GATT（OPO 9 字节帧 `AA len(2LE) 00 00 cmd(2LE) seq len(2LE) payload`）
> 结论：**本 App 当前通用命令实现与真机一致，无需按机型写死**。以下命令均收到 ACK。

## 已验证命令（TX 帧 → 设备 ACK）

| 功能 | 命令字 | payload | 说明 |
|---|---|---|---|
| 电量查询 | 0x0106 | — | 回包 `03 01 64 02 64 03 3C`：左 100% 右 100% 盒 60% |
| 固件查询 | 0x0105 | — | ASCII `"1,2,1.1.0.47,2,2,1.1.0.47"` → 版本 1.1.0.47 |
| 触控配置查询 | 0x0108 | — | 回包含左右耳 6 组按键动作 |
| EQ 查询 | 0x010F | — | 回包为自定义 EQ 数据；预设切换用 0x0406 |
| MISC 状态查询 | 0x010D | `02 00 01 01` 等 | 回包含 06/11/04 等能力项 |
| 能力列表查询 | 0x0205 | `09 01 02 03 05 06` | 回包为能力/参数列表 |
| 降噪-关闭 | 0x0404 | `01 01 01` | |
| 降噪-通透 | 0x0404 | `01 01 02` | |
| 降噪-降噪 | 0x0404 | `01 01 20` | T200 无等级子档 |
| EQ 预设切换 | 0x0406 | `<id>`（0=纯净人声,1=纯粹原音,2=纯净低音,3=浑厚低音,4=明亮,5=动态） | id 与帧一致，真机接受 |
| 游戏模式 | 0x0403 | `06 00/01` | type 0x06 |
| 双设备连接 | 0x0403 | `11 00/01` | type 0x11 |
| 触控手势设置 | 0x0401 | `01 <side> <typeLE> <action>`，如左双击→下一首 = `01 01 01 02 06` | side 左01/右02；type 0x0201 双击、0x0301 三击、0x0401 长按 |
| 查找耳机 | 0x0400 | `01` | 设备会 ACK，但 T200 硬件无此功能（真机无提示音），非协议错误 |

## 其他真机事实

- 能力开关按协议通知动态确认：T200 的 MISC 状态含 0x11（多点连接），因此「双设备连接」开关自动出现；无入耳检测能力 → 开关不出现。
- 充电盒电量：耳机放入充电盒后正常上报（60%），此前显示「—」只是耳机未在盒内。
- 自动回连：应用启动日志 `auto-reconnect last device: realme Buds T200 88:0E:85:XX:XX:XX`，随后握手 + 初始化全部 ACK。
- 该套帧/命令对 Telink（TL）与 OPO 两代方言通用（App 运行时会自动探测方言）。
