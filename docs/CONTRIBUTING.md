# 贡献指南

感谢你愿意帮助改进这个项目！最有价值的贡献是**型号兼容性反馈**与**协议抓包**。

## 反馈耳机型号兼容性

请提交 Issue，并尽量包含：

1. 耳机型号（如 realme Buds T200 / Buds Air 6 Pro）；
2. 手表型号与 Wear OS 版本；
3. 哪些功能可用、哪些不可用（降噪 / 音效 / 手势 / 游戏模式 / 双设备 / 电量 / 固件版本）；
4. 如果方便，附上操作时的 `adb logcat | grep BleBudsRepository` 日志（里面已有 TX/RX 帧的十六进制）。

## 提交代码

1. Fork 本仓库并创建分支；
2. 保持项目结构：`data/` 状态与管理层、`ble/` 传输与协议、`ui/` 界面；
3. 不要引入对单一型号的硬编码特判——能力项应由耳机上报的能力决定；
4. 提交前执行：
   ```bash
   ./gradlew :app:assembleDebug
   ```
5. PR 描述中说明：改了什么、为什么、如何在真机/模拟器上验证。

## 代码风格

- Kotlin 官方风格（`kotlin.code.style=official`）；
- 注释/文档使用中文；
- UI 文案统一放 `res/values/strings.xml`，不要硬编码；
- 新增功能请同步更新 `docs/` 下相关文档。

## 安全与合规

- 不要提交从官方应用提取的原始资源、反编译源码或任何受版权保护的内容；
- 不要提交他人设备的蓝牙地址、日志中的个人信息；
- 不要实现/提交可能损坏设备的操作（例如未经验证的固件写入）。
