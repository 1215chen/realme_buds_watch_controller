# 功能对照与兼容性

## realme Link（手机端）功能 → 手表版支持情况

| realme Link 功能 | 手表版 | 说明 |
|---|---|---|
| 电量（左/右/充电盒） | ✅ | 耳机上报才显示，未上报显示 `—` |
| 降噪（关闭/通透/降噪） | ✅ | 真机已验证 |
| 降噪等级（智能/深度/中等/轻度） | 🟡 | 仅支持该子档的型号显示并可调 |
| 音效预设 | ✅ | 按耳机支持能力生效 |
| 空间音效 / 高清音质(LDAC) / 动态音效 | ❌ | 暂未实现 |
| 触控手势（双击/三击/长按，左右耳独立） | ✅ | 真机已验证 |
| 游戏模式（低延迟） | ✅ | 真机已验证 |
| 双设备连接 | ✅ | 耳机上报支持时显示 |
| 入耳检测 | 🟡 | 只有耳机真的上报佩戴事件才显示开关 |
| 查找耳机 | 🟡 | 仅硬件支持该功能的型号有效；部分型号接受命令但不响 |
| 设备信息（型号/固件/MAC） | ✅ | 真机已验证 |
| 固件 OTA | ❌ | 未实现 |
| 累计使用时长 / 耳机自检 / 日志导出 | ❌ | 未实现 |
| AI 问答 / AI 翻译 | ❌ | 依赖手机端，手表端不做 |

## 耳机型号兼容性

本项目按**协议族**通用适配，不做型号白名单：

- ✅ **已验证**：realme Buds T200（BLE GATT / OPO 帧；全部控制项生效）
- 🟡 **理论支持**：realme Buds T 系列、Buds Air 系列、Buds Q / Air Neo 等使用相同协议的 TWS；部分 OPPO/OnePlus Enco 型号
- ❌ **不支持**：非 realme/OPPO 品牌（仅标准 BLE 电量/信息）；头戴/颈挂等协议不同的设备

判断方式：能连上并在「设备信息」读到型号/固件，且切降噪/音效时耳机有实际变化即为支持。

## 如何反馈型号兼容性

提交 Issue 时请附：
1. 耳机型号 + 手表型号 + Wear OS 版本；
2. 哪些功能可用/不可用；
3. `adb logcat | grep BleBudsRepository` 日志（已含 TX/RX 帧）。
