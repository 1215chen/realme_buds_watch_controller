# 通信协议说明（互操作研究整理）

> 本文档由本项目维护者根据对 realme 客户端行为的公开可见信息与**自行抓取的真机空中帧**整理，
> 仅用于互操作研究与个人学习。命令表在 **realme Buds T200（Wear OS 手表 BLE GATT 连接）** 上实测通过。

## 1. 传输层

| 通道 | 说明 |
|---|---|
| BLE GATT | 扫描 → 连接 → 服务发现 → 写特征 + 通知特征。本项目优先使用，并自动查找私有服务（按「可写 + 可通知」属性发现） |
| 经典蓝牙 RFCOMM/SPP | 部分型号（如 realme Air 系列）控制通道走 SPP；需系统已配对，使用 OPO 私有 UUID / SPP 0x1101 |
| 标准 GATT | 兜底：BAS（0x180F/0x2A19）读电量、DIS（0x180A/0x2A24/0x2A26）读型号/固件 |

## 2. 两种帧方言（运行时自动探测）

**TL 帧（Telink，5 字节头，大端）**

```
cmd(2B BE) | seq(1B) | len(2B BE) | payload(len B)
```

**OPO 帧（9 字节头，小端）**

```
AA | len(2B LE) | 00 00 | cmd(2B LE) | seq(1B) | len(2B LE) | payload(len B)
```

- `cmd` 低 15 位为命令 id，bit15 置位表示设备 → App 方向的响应/通知；
- 响应帧通常为 `cmd | 0x8000`；
- 无 CRC；加载初始化时先发查询，收到第一帧后自动锁定方言。

## 3. 实测命令表（realme Buds T200）

| 功能 | 命令 | payload | 说明 |
|---|---|---|---|
| 电量查询 | `0x0106` | — | 回包 `count, (side, level)*`；side 1=左 2=右 3=盒，bit7=充电 |
| 固件查询 | `0x0105` | — | ASCII `"1,2,<版本>,2,2,<版本>"` |
| 触控配置查询 | `0x0108` | — | 回包含左右耳按键动作 |
| 音效查询 | `0x010F` | — | 回包为 EQ 数据 |
| MISC 状态查询 | `0x010D` | 子类型 | 回包含游戏模式/多点/入耳等能力位 |
| 能力列表查询 | `0x0205` | 列表 | 回包为能力/参数列表 |
| 降噪-关闭 | `0x0404` | `01 01 01` | |
| 降噪-通透 | `0x0404` | `01 01 02` | |
| 降噪-降噪 | `0x0404` | `01 01 20` | 支持等级的型号另有等级子档 |
| 音效切换 | `0x0406` | `<id>` | id 顺序：0 纯净人声 / 1 纯粹原音 / 2 纯净低音 / 3 浑厚低音 / 4 明亮 / 5 动态 |
| 游戏模式 | `0x0403` | `06 00/01` | MISC 子类型 0x06 |
| 双设备连接 | `0x0403` | `11 00/01` | MISC 子类型 0x11 |
| 触控手势设置 | `0x0401` | `01 <side> <typeLE> <action>` | side 左 01 / 右 02；type 0x0201 双击、0x0301 三击、0x0401 长按；action 见下 |
| 查找耳机 | `0x0400` | `01` | 仅硬件支持该功能的型号有效（部分型号 ACK 但无动作） |

**手势动作码（实测）**：播放/暂停 `0x01`、语音助手 `0x04`、上一首 `0x05`、下一首 `0x06`、音量+ `0x0B`、音量- `0x0C`、无操作 `0x00`。

## 4. 能力（由耳机上报决定 UI）

- 双设备连接：MISC 状态里出现多点连接类型（0x11）→ 显示开关；
- 入耳检测：只有真正收到「已佩戴」事件才显示开关；
- 降噪等级：ANC 状态包中带等级字段才显示等级选项；
- 充电盒电量：上报了才显示，未上报显示 `—`。
